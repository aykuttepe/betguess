# Plan feature
For mixed features divide responsibility: Claude backend/API and Codex frontend/UI. List endpoints, request/response shapes, errors and authentication. Ask approval before implementation. Keep the plan brief and avoid unnecessary agent calls.

Check applicable docs/QUALITY-GATES.md and record commands and actual outcomes. Never claim gate passed if a check was skipped or unavailable.
