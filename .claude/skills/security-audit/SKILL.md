# Security audit
Scope review to the relevant backend/auth/data changes. Check access control, injections, sensitive output, untrusted input, dependency risks. Never open secret material. Report prioritized evidence and mitigations; no automatic deployments.

Check applicable docs/QUALITY-GATES.md and record commands and actual outcomes. Never claim gate passed if a check was skipped or unavailable.
