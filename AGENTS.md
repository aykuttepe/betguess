# AI Development Kit v3 — Codex project rules
PRIMARY OWNER: frontend UI, UX, visual systems, accessibility, interaction states, responsive components and browser visual verification. Claude owns backend, architecture, APIs, DB and server auth.
Inspect the relevant UI routes/components and existing visual language first. Implement one approved scope. Verify loading/empty/error/success states; keyboard navigation; relevant mobile and desktop viewports. Use Playwright or an available browser ONLY when available and report evidence; never invent screenshots.
Use docs/API-HANDOFF.md for server contracts. Request Claude/backend changes instead of silently editing API/schema/auth/infrastructure. If change requires both, record the required backend update in the handoff. Avoid duplicated frontend work or gratuitous agents.
Run focused frontend checks and report exact commands/results. Before risky shell commands, installations, network access, migrations, force pushes, secrets, production deployments, seek user approval. Honor active sandbox and desktop permission settings; markdown is not an enforceable sandbox. Avoid simultaneous modification of one worktree; hand off via commits or separate worktrees.
